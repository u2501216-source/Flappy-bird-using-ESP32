# Flappy-bird-using-ESP32
This project implements a simple Flappy Bird-style game using an ESP32 microcontroller and a 128×64 OLED display. The ESP32 controls the game logic, including bird movement, gravity, obstacle generation, collision detection, and score tracking.

Players can control the bird using physical push buttons or a mobile phone connected to the ESP32's Wi-Fi hotspot. The OLED displays the game in real time, while an LED provides a visual indicator during gameplay. A restart button allows players to start a new game after a collision.

Components Used:

*ESP32 Dev Module
*SSD1306 OLED display (128×64)
*Two push buttons
*LED and 560 Ω resistor
*Arduino IDE

Technologies: Embedded C++, Arduino IDE, ESP32 Wi-Fi, and OLED graphics.

Key Features:

*Real-time gameplay on the OLED
*Physical button controls
*Mobile phone controls through a web interface
*Score tracking and collision detection
*Game restart functionality
